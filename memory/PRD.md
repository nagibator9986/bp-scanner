# AI BP Scanner - PRD (Product Requirements Document)

## Original Problem Statement
Создать работающее приложение для сквозного анализа бизнес-процессов и их автоматизации.
Входные данные: опросник по процессу и департаменту, подгрузка документов.
Выходные данные: анализ, BPMN AS-IS карта, анализ на реинжиниринг, TO-BE, автоматизация на N8N.

## Architecture
- **Backend**: Python FastAPI + MongoDB (Motor async driver)
- **Frontend**: React 19 + Tailwind CSS + Shadcn/UI
- **AI**: OpenAI GPT-5.2 via Emergent LLM key (emergentintegrations library)
- **BPMN**: bpmn-js for rendering BPMN 2.0 XML
- **Charts**: Recharts for scoring/analytics visualization

## User Personas
1. **Бизнес-аналитик** - Создаёт подразделения, заполняет анкеты, загружает документы, анализирует результаты
2. **Руководитель трансформации** - Просматривает портфельный дашборд, приоритизирует инициативы
3. **IT-архитектор** - Работает с BPMN моделями и N8N workflows

## Core Requirements (Static)
- JWT-аутентификация
- Управление подразделениями (CRUD)
- Адаптивный опросник (6 секций с условной логикой)
- Загрузка документов (PDF, DOCX, XLSX, PPTX, TXT)
- AI-анализ документов и анкеты → извлечение процессов
- Генерация BPMN AS-IS моделей
- Скоринг процессов (6 измерений)
- Рекомендации по 3 категориям (автоматизация, цифровизация, AI реинжиниринг)
- TO-BE модели с BPMN
- N8N workflow генерация
- Портфельный дашборд
